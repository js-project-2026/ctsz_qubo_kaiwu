1. 研究目标：从“差异表达列表”到“非冗余基因面板”

本研究的核心目标，并非生成又一张单细胞转录组差异表达基因列表，而是解决一个更具转化生物学意义的问题： 如何从高维单细胞数据中，筛选出一组数量极为精简（约 50 个）、但作为集合能最大程度解释连续细胞状态转变（造血分化轨迹）的基因面板。

不同于按差异倍数或相关性排序取前 N 个基因，我们将此问题明确定义为组合优化。 理想诊断或检测面板的成员应联合携带目标状态的最大信息，同时相互间信息冗余最小。 这在湿实验转化（靶向引物组、探针组、CRISPR 筛选文库）中具有直接的成本与解读优势：买的是一盒探针，不是 5,000 个 HVG。

2. 当前研究方法与进展

我们以 Romero 等 (2025) 的 QUBO 模型为框架，应用到独立的 CRISPR 造血分化数据集 GSE308682， 筛选能追踪造血进程（扩散拟时间 T，iroot = 最低 HBE1 残差）的关键基因。 代价函数同时用互信息量化每个基因与轨迹的相关性 I，以及基因两两冗余 R（论文式 (4)）：

minF [ −α ∑i Ii Fi + (1−α) ∑i,j Rij Fi Fj ]
Q = (1−α)R − α diag(I)

搜索 α 使无约束解约有 k = 50 个 1。这是典型 QUBO，可映射到退火机与相干伊辛机。

对照方法：LASSO 路径、随机森林。特征选择使用全部 10,691 个质控细胞；z-score Ridge MSE 仅在掩码固定后做 70%/30% 训练/测试划分，无独立验证集调 α 或 k。

当前求解器：D-Wave Ocean TabuSampler（SOLVER="tabu"）， 经典 CPU 启发式，不是 QPU。Ocean 模拟退火同样是经典算法。 Leap hybrid 与 Kaiwu CIM 已接入代码，尚未上机。 同一 Q 上已跑通 Kaiwu 本地 tabu（无需 CIM 密钥）：|F*|=52，E=−1.7737，与 Ocean 重叠 48/50（PASS）。 本次全规模数字来自加长超时与零初态的 Ocean Tabu，以及该 Kaiwu 对照。

求解器规模：小规模与全规模均命中 k=50

在 500 个基因的缩减数据（RUNX1 残差为 T）上，Tabu 给出低冗余面板： α* = 0.57，能量 −2.67，|F*|=50。 扩展至完整 5,000 高变基因、DPT 为 T 时，此前默认 20 ms/read 与随机初态给出稠密高能解（|F*|=2,456，E=+71,715）。 将超时设为 10,000 ms/read、首个初态全零后，α 二分命中 k=50：α* = 0.3945，能量 −1.7771，|F*|=50（验收 PASS）。 公式与全规模搜索均成立；CIM 不再是“找回 50 个基因”的唯一路径，而是同一 Q 上的硬件对照。

3. 当前结果的生物学意义

尽管此前短超时 Tabu 未给出稀疏解，校正后的全规模掩码已是 k=50，生物学验证更直接。

轨迹一致性

入选基因高度一致，对准造血向红系分化的核心进程，而非论文的内皮轴线。

HBE1 HBZ HBG2 HBA2 ALAS2 SLC25A37

珠蛋白、血红素合成酶、谱系转录因子。RAMP2 / APLN / THY1 不在其中——数据是造血，不是 hESC→内皮。

信息结构 ≠ 线性预测冠军

该基因集预测拟时间优于全部 5,000 基因（图 2），说明捕捉到轨迹关键信息。 QUBO 的目标是低冗余信息面板，与线性回归的最小二乘有本质不同。 略差于 LASSO 的 MSE，在转化场景下可以接受，甚至是预期：面板要的是可下单的非冗余集合，不是最优线性拟合。

1. Goal: from a DE list to a non-redundant gene panel

The aim is not another differential-expression list. It is a translational question: from high-dimensional scRNA-seq, recover a ~50-gene panel that, as a set, explains a continuous cell-state trajectory (hematopoietic differentiation) as well as a much larger transcriptome.

Ranking by fold-change or correlation and taking the top N is the wrong object. We state the problem as combinatorial optimization: members of a diagnostic cassette should jointly carry maximal information about the state and minimal information about each other. That is what a wet lab actually orders — primers, probes, a CRISPR follow-up library — not 5,000 HVGs.

2. Methods and current progress

We use the Romero et al. (2025) QUBO on an independent CRISPR hematopoiesis dataset, GSE308682, to track hematopoietic progression (diffusion pseudotime T; iroot = lowest HBE1 residual). Mutual information supplies per-gene relevance I and pairwise redundancy R. The cost is paper Eq. (4):

minF [ −α ∑i Ii Fi + (1−α) ∑i,j Rij Fi Fj ]
Q = (1−α)R − α diag(I)

α is searched so an unconstrained solver returns about k = 50 ones. That is a native QUBO, and it maps onto annealers and coherent Ising machines.

Baselines: LASSO path and random forest. Feature selection uses all 10,691 QC cells. Z-scored Ridge MSE uses a 70/30 train/test split only after the gene mask is fixed. There is no validation split for α or k.

Current solver: D-Wave Ocean TabuSampler (SOLVER="tabu") — a classical CPU heuristic, not a QPU. Ocean simulated annealing is likewise classical. Leap hybrid and Kaiwu CIM are wired in code and have not been run at this scale. Kaiwu local tabu on the same Q (no CIM key) returned |F*|=52, E=−1.7737, Ocean overlap 48/50 (PASS). The full-scale numbers below are Ocean tabu (long timeout, zero init) plus that Kaiwu compare.

Scale: both 500- and 5,000-gene tabu hit k=50

On a 500-gene reduction (RUNX1 residual as T), tabu returned a healthy panel: α* = 0.57, energy −2.67, |F*|=50. At the full 5,000 HVGs with DPT as T, Ocean’s default 20 ms/read and a random initial state gave a dense high-energy mask (|F*|=2,456, E=+71,715). With 10,000 ms/read and a zero first initial state, α-bisection hit k=50: α* = 0.3945, energy −1.7771, |F*|=50 (PASS). CIM is no longer the only way to recover 50 genes; it is a hardware comparison on the same Q.

3. Biological meaning of the current results

The short-timeout tabu run did not sparsify. The corrected full-scale mask is k=50, so the biology is now a 50-gene panel.

Trajectory concordance

Selected genes align with hematopoietic-to-erythroid progression, not the paper’s endothelial axis.

HBE1 HBZ HBG2 HBA2 ALAS2 SLC25A37

Globins, heme biosynthesis, lineage TFs. RAMP2 / APLN / THY1 are absent — this matrix is hematopoiesis, not hESC→EC.

Information structure is not a linear-fit contest

The set predicts pseudotime better than all 5,000 genes (Figure 2): it captured the trajectory. QUBO optimizes a low-redundancy information panel, not least squares. A worse MSE than LASSO is acceptable — and expected — if the product is a cassette a lab can order.

4. Next: hardware comparison, not cardinality rescue

Full-scale tabu with a correct timeout and zero init already returns |F*|=50 and negative energy. Classical Kaiwu tabu on the same Q is done (overlap 48/50). The same Q can still go to the QBoson coherent Ising machine (CIM) through the Kaiwu SDK (SOLVER="kaiwu_cim") to compare energy and gene membership, not to recover k.

5. Closing statement

We have turned biological panel design into a QUBO and obtained |F*|=50 with negative energy at both 500 and 5,000 genes. The earlier full-scale failure was Ocean’s 20 ms default timeout and a random initial state, not a broken formula. CIM / Leap are hardware comparisons. The 50-gene list is on the comparison page; Ridge MSE still has selection leakage.
