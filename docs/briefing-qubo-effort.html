1. 研究目标：从“差异表达列表”到“非冗余基因面板”

本研究的核心目标，并非生成又一张单细胞转录组差异表达基因列表，而是解决一个更具转化生物学意义的问题： 如何从高维单细胞数据中，筛选出一组数量极为精简（约 50 个）、但作为集合能最大程度解释连续细胞状态转变（造血分化轨迹）的基因面板。

不同于按差异倍数或相关性排序取前 N 个基因，我们将此问题明确定义为组合优化。 理想诊断或检测面板的成员应联合携带目标状态的最大信息，同时相互间信息冗余最小。 这在湿实验转化（靶向引物组、探针组、CRISPR 筛选文库）中具有直接的成本与解读优势：买的是一盒探针，不是 5,000 个 HVG。

2. 当前研究方法与进展

我们以 Romero 等 (2025) 的 QUBO 模型为框架，应用到独立的 CRISPR 造血分化数据集 GSE308682， 筛选能追踪造血进程（扩散拟时间 T，iroot = 最低 HBE1 残差）的关键基因。 代价函数同时用互信息量化每个基因与轨迹的相关性 I，以及基因两两冗余 R（论文式 (4)）：

minF [ −α ∑i Ii Fi + (1−α) ∑i,j Rij Fi Fj ]
Q = (1−α)R − α diag(I)

搜索 α 使无约束解约有 k = 50 个 1。这是典型 QUBO，可映射到退火机与相干伊辛机。

对照方法：LASSO 路径、随机森林。特征选择使用全部 10,691 个质控细胞；线性 MSE 仅在掩码固定后做 70%/30% 训练/测试划分，无独立验证集调 α 或 k。

当前求解器：D-Wave Ocean TabuSampler（SOLVER="tabu"）， 经典 CPU 启发式，不是 QPU。Ocean 模拟退火同样是经典算法。 Leap hybrid 与 Kaiwu CIM 已接入代码，尚未产生下列全规模数字。

求解器规模：小规模成立，全规模失败

在 500 个基因的缩减数据（RUNX1 残差为 T）上，Tabu 成功给出低冗余面板： α* = 0.57，能量 −2.67，|F*|=50。 公式有效。当扩展至完整 5,000 高变基因、DPT 为 T 时，Tabu 返回稠密高能量解： α* = 0.50，能量 +71,715，|F*|=2,456（目标为 50）。 问题复杂度已超出该经典启发式；这排除了“算法公式失效”的解释，并把瓶颈明确指向全连接 5,000 比特 QUBO 的搜索。

3. 当前结果的生物学意义

尽管经典求解器未给出目标稀疏解，现有结果仍有明确的生物学验证价值。

轨迹一致性

入选基因高度一致，对准造血向红系分化的核心进程，而非论文的内皮轴线。

HBE1 HBB HBD ALAS2 KLF1 RUNX1

珠蛋白、血红素合成酶、谱系转录因子。RAMP2 / APLN / THY1 不在其中——数据是造血，不是 hESC→内皮。

信息结构 ≠ 线性预测冠军

该基因集预测拟时间优于全部 5,000 基因（图 2），说明捕捉到轨迹关键信息。 QUBO 的目标是低冗余信息面板，与线性回归的最小二乘有本质不同。 略差于 LASSO 的 MSE，在转化场景下可以接受，甚至是预期：面板要的是可下单的非冗余集合，不是最优线性拟合。

1. Goal: from a DE list to a non-redundant gene panel

The aim is not another differential-expression list. It is a translational question: from high-dimensional scRNA-seq, recover a ~50-gene panel that, as a set, explains a continuous cell-state trajectory (hematopoietic differentiation) as well as a much larger transcriptome.

Ranking by fold-change or correlation and taking the top N is the wrong object. We state the problem as combinatorial optimization: members of a diagnostic cassette should jointly carry maximal information about the state and minimal information about each other. That is what a wet lab actually orders — primers, probes, a CRISPR follow-up library — not 5,000 HVGs.

2. Methods and current progress

We use the Romero et al. (2025) QUBO on an independent CRISPR hematopoiesis dataset, GSE308682, to track hematopoietic progression (diffusion pseudotime T; iroot = lowest HBE1 residual). Mutual information supplies per-gene relevance I and pairwise redundancy R. The cost is paper Eq. (4):

minF [ −α ∑i Ii Fi + (1−α) ∑i,j Rij Fi Fj ]
Q = (1−α)R − α diag(I)

α is searched so an unconstrained solver returns about k = 50 ones. That is a native QUBO, and it maps onto annealers and coherent Ising machines.

Baselines: LASSO path and random forest. Feature selection uses all 10,691 QC cells. Linear MSE uses a 70/30 train/test split only after the gene mask is fixed. There is no validation split for α or k.

Current solver: D-Wave Ocean TabuSampler (SOLVER="tabu") — a classical CPU heuristic, not a QPU. Ocean simulated annealing is likewise classical. Leap hybrid and Kaiwu CIM are wired in code and did not produce the full-scale numbers below.

Scale: the formula holds; full-scale tabu does not

On a 500-gene reduction (RUNX1 residual as T), tabu returned a healthy panel: α* = 0.57, energy −2.67, |F*|=50. The model works. At the full 5,000 HVGs with DPT as T, tabu returned a dense high-energy mask: α* = 0.50, energy +71,715, |F*|=2,456 versus a target of 50. Complexity has outrun this classical heuristic. That rules out “the formula is broken.” The bottleneck is search on a fully connected 5,000-bit QUBO.

3. Biological meaning of the current results

The classical solver did not return the intended sparse optimum. The biology still validates the setup.

Trajectory concordance

Selected genes align with hematopoietic-to-erythroid progression, not the paper’s endothelial axis.

HBE1 HBB HBD ALAS2 KLF1 RUNX1

Globins, heme biosynthesis, lineage TFs. RAMP2 / APLN / THY1 are absent — this matrix is hematopoiesis, not hESC→EC.

Information structure is not a linear-fit contest

The set predicts pseudotime better than all 5,000 genes (Figure 2): it captured the trajectory. QUBO optimizes a low-redundancy information panel, not least squares. A worse MSE than LASSO is acceptable — and expected — if the product is a cassette a lab can order.

4. Next: quantum hardware is the necessary move

Full-scale tabu failed because the instance is hard (dense 5,000×5,000 Q), not because the biology is mis-specified. Next we migrate that instance to quantum-heuristic hardware: the QBoson coherent Ising machine (CIM) through the Kaiwu SDK (SOLVER="kaiwu_cim"; KAIWU_USER_ID + KAIWU_SDK_CODE). That run is a scientific result, not a connectivity test.

We do not pre-claim that CIM will beat LASSO on MSE, or replicate Romero Table 1 on this tissue. If |F*| remains ~p/2, we record it and move the question to α-search and hardware fit.

5. Closing statement

We have turned biological panel design into a scalable QUBO, and we have validated it at small scale. The full-scale solve is the signal that this instance belongs on quantum and quantum-heuristic hardware. The CIM run is how we expect to deliver the first low-redundancy, high-information 50-gene transcriptome panel for this hematopoietic model, and to move scRNA-seq toward an assay cassette rather than a gene list.
