3. What the code changed

FileChange
dppiv_logit.py 400-d dipeptide composition (count / (L−1); zeros when L < 2). feature_matrix accepts seq, dpc, len, and + combinations. Length bins 2–5, 6–10, 11+, and balance_indices to downsample each bin to equal class counts.
dppiv_suite.py New comparison script: L2 logistic, RBF SVM (C in {0.1, 1, 10}), and histogram gradient boosting (depth 3 or 6) on the same split. Cross-validation uses training MCC only, then reports within-bin scores before and after the length-balanced refit.
tests/test_dppiv_logit.py Dipeptide row of KPW sums to 1; a single residue is all zeros; seq+dpc+len has 481 columns. Balancing keeps equal positive and negative counts inside each occupied bin.

dppiv_logit.py --download still reports only the three L2 models len, seq, and seq+len. The full comparison is dppiv_suite.py --download. Fingerprints (Estate, MACCS, PubChem, FP4) and the paper’s stack of 50 base models were not reimplemented.
