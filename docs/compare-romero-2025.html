5. What this run can and cannot say

  • Can: The pipeline is in the paper’s protocol family (residuals, ~5k genes, trajectory T, unconstrained QUBO + tabu) and now returns a k=50 mask with negative energy. Q∩LASSO 24/50 (48%) matches their 44% at the same cardinality.
  • Cannot: Replicate Table 1 (planted synthetic sources) or claim the hESC/PC9 unique-gene / GO results. Ridge MSE is leaky (selection on all QC cells).
  • Next: Optional Leap hybrid / Kaiwu CIM on the same Q (classical Kaiwu tabu is already done: overlap 48/50). Enrichment and a true hold-out for selection remain open.
