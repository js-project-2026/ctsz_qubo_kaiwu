1. 数据与划分

1.1 合成数据（论文 §2.3 / USE_REAL_DATA = False）

qubo_model.generate_synthetic_data 按 Romero 等 §2.3 生成相关高斯特征与非线性响应： 默认 n = 10,000 样本、p = 50 特征，seed=42。 互信息、QUBO、LASSO、随机森林均在全部 10,000 行上计算，没有训练 / 验证 / 测试划分。 仅当随后调用线性探针 MSE 时，才对已选出的列做 70% / 30% 划分（见下）。 该设置对应论文 Table 1 一类的“种植源特征召回”，不是本次 GSE308682 重跑。

1.2 真实测试数据 GEO GSE308682

10x 文件不在 git 中。将 QUBO_DATA_DIR 指向含下列文件的目录：

  • GSE308682_filtered_matrix.mtx.gz
  • GSE308682_filtered_features.tsv.gz
  • GSE308682_filtered_barcodes.tsv.gz
  • GSE308682_feature_reference.csv.gz（CRISPR 特征参考；计数矩阵可选）

GEO 发布的是 Cell Ranger filtered 矩阵，本仓库不再做第二层“研究级”训练/验证/测试细胞划分。 流程是：全部 barcode → 质控 → 全部通过质控的细胞用于特征选择 → 仅线性 MSE 再切分。

测试（仅线性 MSE） 特征掩码固定之后，evaluate_selected_features 用 sklearn.model_selection.train_test_split （test_size=0.3，random_state=42，打乱） 把细胞划成训练集与测试集；列在训练集上 z-score，再拟合 Ridge(α=1)（Pearson 残差上 OLS 会溢出），MSE 在测试集上报告。 各方法（QUBO / LASSO / RF / 全部 5,000 基因）各自独立切一次，种子相同。 约 70% 训练 / 30% 测试 （10,691 细胞时约 7,483 / 3,208）

因此：QUBO 基因列表见过全部细胞（含后来计入测试 MSE 的细胞）。 测试 MSE 评估的是“给定已选基因、线性模型对新细胞的拟合”， 不是独立 hold-out 上的特征选择泛化。论文真实数据部分也以重叠 / 独特基因 / GO 为主，并不以该线性 MSE 为标题指标。
