1. 数据与划分

1.1 合成数据（论文 §2.3 / USE_REAL_DATA = False）

qubo_model.generate_synthetic_data 按 Romero 等 §2.3 生成相关高斯特征与非线性响应： 默认 n = 10,000 样本、p = 50 特征，seed=42。 互信息、QUBO、LASSO、随机森林均在全部 10,000 行上计算，没有训练 / 验证 / 测试划分。 仅当随后调用线性回归 MSE 时，才对已选出的列做 70% / 30% 划分（见下）。 该设置对应论文 Table 1 一类的“种植源特征召回”，不是本次 GSE308682 重跑。

1.2 真实测试数据 GEO GSE308682

10x 文件不在 git 中。将 QUBO_DATA_DIR 指向含下列文件的目录：

  • GSE308682_filtered_matrix.mtx.gz
  • GSE308682_filtered_features.tsv.gz
  • GSE308682_filtered_barcodes.tsv.gz
  • GSE308682_feature_reference.csv.gz（CRISPR 特征参考；计数矩阵可选）

GEO 发布的是 Cell Ranger filtered 矩阵，本仓库不再做第二层“研究级”训练/验证/测试细胞划分。 流程是：全部 barcode → 质控 → 全部通过质控的细胞用于特征选择 → 仅线性 MSE 再切分。

测试（仅线性 MSE） 特征掩码固定之后，evaluate_selected_features 用 sklearn.model_selection.train_test_split （test_size=0.3，random_state=42，打乱） 把细胞划成训练集与测试集；LinearRegression 只在训练集拟合，MSE 在测试集上报告。 各方法（QUBO / LASSO / RF / 全部 5,000 基因）各自独立切一次，种子相同。 约 70% 训练 / 30% 测试 （10,691 细胞时约 7,483 / 3,208）

因此：QUBO 基因列表见过全部细胞（含后来计入测试 MSE 的细胞）。 测试 MSE 评估的是“给定已选基因、线性模型对新细胞的拟合”， 不是独立 hold-out 上的特征选择泛化。论文真实数据部分也以重叠 / 独特基因 / GO 为主，并不以该线性 MSE 为标题指标。

6. 本次运行能说明与不能说明的

  • 能：流程属于论文方案族（残差、约 5k 基因、轨迹 T、无约束 QUBO + tabu）。 Q∩LASSO 比例（约 50%）与其 k=50 时的 44% 并非完全不同量级。
  • 不能：复现 Table 1（种植合成源）或宣称 hESC/PC9 独特基因 / GO 结果。 正能量且 |F*|≈p/2 意味着报告的基因列表不是 k=50 的 QUBO 解。
  • 下一步：在 p=5,000 上得到 |F*|=50（更强的 α 搜索、更多 tabu reads，或 Leap hybrid），再做重叠/富集。 在此之前，本项目中唯一健康的 k=50 真实数据掩码是更早的 500-HVG RUNX1 残差运行，那是不同的 T 与基因池。
